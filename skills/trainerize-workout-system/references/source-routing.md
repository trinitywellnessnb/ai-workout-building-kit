# Source Routing

## Required project sources

- `README.md`
- `FILE-MAP.md`
- `PROJECT-INSTRUCTIONS.md`
- `trainer-profile.yaml`
- `programming-preferences.yaml`
- `approval-policy.yaml`
- `Trainerize-System-Registry-Template.xlsx`

## Manual routing

| Task | Read first |
| --- | --- |
| Personalization | README, questionnaire, three configuration files |
| Movement inventory | Project Instructions, execution rulebook, Movement Registry |
| Workout inventory and reuse | Automation architecture, Workout Builder manual, Workout Registry |
| Workout or program generation | Structured Workout Architecture, Master Rulebook, verified registries |
| Live Workout Builder entry | Workout Builder Operational Manual, Work Mode Execution Rulebook |
| Calendar scheduling | Calendar Engagement Funnel Rulebook, Workout Builder Operational Manual |
| Coach correction | Automation architecture, execution rulebook, affected registry records |
