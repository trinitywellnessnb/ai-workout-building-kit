# Generalization Map

The universal manuals retain the programming, workflow, verification, recovery, and calendar logic of the source documents. The following categories were generalized:

| Source content | Generalized treatment |
| --- | --- |
| Personal names | Replaced with `the trainer` or `the coach` |
| Trinity Wellness branding | Removed or replaced with trainer-configured business information |
| Personal approval statements | Replaced with explicit trainer approval |
| Personal social tags and links | Replaced with verified profile and configuration values |
| Agent Mode terminology | Updated to ChatGPT Work Mode terminology |
| Account-specific movement data | Excluded from the package |
| Account-specific workout and program records | Excluded from the package |
| Naming architecture | Retained as the recommended default and made configurable |

The manuals do not claim that trainer-specific business rules are official Trainerize platform requirements. Verified current platform behavior controls navigation and interface translation.
