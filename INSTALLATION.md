# Installation

## Option 1 Direct project upload

1. Download or clone this repository.
2. Create a dedicated ChatGPT Project.
3. Add `README.md`, `START-HERE.md`, `FILE-MAP.md`, and `project-instructions/PROJECT-INSTRUCTIONS.md` to the project sources.
4. Add all six documents from `manuals/`.
5. Add the three YAML files from `configuration/`.
6. Add `templates/Trainerize-System-Registry-Template.xlsx`.
7. Add the onboarding questionnaire and readiness checklist.
8. Ask ChatGPT to read the source hierarchy and guide personalization.

## Option 2 Connected Google Drive folder

1. Download or clone this repository.
2. Place one complete copy in a dedicated Google Drive folder.
3. Connect that folder to the ChatGPT Project as an available source.
4. Keep filenames unchanged so instructions and future skills can resolve them reliably.
5. Confirm that ChatGPT can locate the README, configuration, manuals, and master registry workbook before beginning inventory.

## Skill installation

The initial version works through the Project Instructions even before an optional skill is installed. When the packaged skill is present in `skills/`, install it through ChatGPT's Skills interface using the supplied skill folder or archive. After installation, keep the manuals, configuration, and registries in the project sources; the skill routes tasks but does not replace those source files.

On mobile, open the ChatGPT sidebar, select Plugins, open the Skills tab, and use the available skill import or creation workflow. Interface wording may change, so follow the current Skills screen rather than relying on an old screenshot.

## First-run sequence

1. Complete the personalization questionnaire.
2. Populate trainer configuration.
3. Inventory movements.
4. Review the Movement Registry.
5. Inventory workouts.
6. Review the Workout Registry.
7. Inventory programs.
8. Review the Program Registry.
9. Generate one calibration workout.
10. Approve the draft before live entry.
11. Save and read back the Trainerize workout.
12. Synchronize the registry and execution log.
