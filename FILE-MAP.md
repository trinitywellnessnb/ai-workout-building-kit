# File Map

Use these exact filenames so project instructions, manuals, and future skills can locate the correct source consistently.

| Filename | Purpose | Authority |
| --- | --- | --- |
| `trainer-profile.yaml` | Business identity, contact details, audience, voice, and brand settings | Trainer configuration |
| `programming-preferences.yaml` | Naming, workout, program, and execution defaults | Trainer configuration |
| `approval-policy.yaml` | Defines automatic, approval-required, and prohibited actions | Trainer configuration |
| `Trainerize-System-Registry-Template.xlsx` | All-in-one editable workbook | Working system record |
| `Movement-Registry-Template.csv` | Standalone movement inventory | External index; Trainerize remains authoritative |
| `Workout-Registry-Template.csv` | Standalone workout inventory | External index; Trainerize remains authoritative |
| `Program-Registry-Template.csv` | Standalone program inventory | External index; Trainerize remains authoritative |
| `Client-Program-Build-Template.csv` | Approved program and workout build contract | Execution instruction surface |
| `Calendar-Build-Template.csv` | Calendar and engagement scheduling plan | Execution instruction surface |
| `Work-Mode-Execution-Log-Template.csv` | Resumable action, checkpoint, and recovery log | Execution history |

Do not rename synchronized templates after setup unless every project instruction and skill reference is updated at the same time.
