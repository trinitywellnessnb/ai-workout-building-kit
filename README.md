# AI Workout Building Kit

Version 0.1.0

![AI Workout Building Kit workflow](assets/ai-workout-building-kit-banner.png)

Independent compatibility toolkit for trainers using ChatGPT Work Mode with Trainerize.

This repository is a trainer-neutral operating package for using ChatGPT Work Mode with Trainerize. It combines workout-programming standards, Trainerize execution procedures, calendar-engagement rules, blank registries, and personalization files.

The package does not contain a trainer's private exercise library, saved workouts, client records, credentials, brand assets, or contact information. Each trainer personalizes a private copy after installation.

## What it does

The kit creates a repeatable path from a trainer's own programming methods to verified Trainerize content:

`Trainer preferences → movement registry → workout registry → program design → Trainerize build → calendar scheduling → read-back verification`

ChatGPT Work Mode uses the manuals to determine how to plan and validate work, the configuration files to understand the individual trainer, and the registries to preserve exact Trainerize exercise and workout identities.

## Start here

1. Read `START-HERE.md` and `INSTALLATION.md`.
2. Complete the trainer questionnaire in `onboarding/`.
3. Add the manuals, project instructions, and configuration to a dedicated ChatGPT Project or connected Google Drive folder.
4. Use `Trainerize-System-Registry-Template.xlsx` to inventory the trainer's own Trainerize account.
5. Run one calibration workout before authorizing a large live build.

## Repository map

- `manuals/` contains the generalized operating and programming documents.
- `configuration/` contains trainer-editable profile and policy files.
- `templates/` contains the blank registry and build workbook.
- `assets/` contains README and product visuals.
- `FILE-MAP.md` defines synchronized filenames and roles.
- `project-instructions/` contains the instructions for the dedicated ChatGPT Project.
- `onboarding/` contains the personalization questionnaire and readiness checklist.
- `source-notes/` explains the source hierarchy and generalization decisions.
- `skills/` contains the installable Trainerize Workout System routing skill.

## Source hierarchy

When instructions conflict, use this order:

1. Safety, scope of practice, and client-specific restrictions
2. Explicit current trainer instruction
3. Verified Trainerize platform behavior
4. Trainer configuration files
5. Workout Generation Master Rulebook
6. Structured Workout Architecture
7. Workout Builder Operational Manual
8. Calendar Engagement Funnel Rulebook
9. Formatting preferences

Trainerize remains authoritative for what is actually saved in the trainer's account. The external registries are indexes and working records, not substitutes for read-back verification.

## Privacy

Do not place passwords, payment information, protected health information, or unnecessary client identifiers in this repository. Sign in to Trainerize through the trainer's own authenticated browser session.

## Product status

Version 0.1 is the generalized foundation. It does not include payment processing, a hosted questionnaire, automatic package generation, or a public update service.

This is an independently developed compatibility product and is not affiliated with or endorsed by Trainerize or OpenAI. See `DISCLAIMER.md`.

## Example requests

After setup, a trainer can ask:

> Inventory the movements in my Trainerize exercise library and populate the Movement Registry. Preserve exact titles and stop on uncertain classifications.

> Build a six-week upper-body calisthenics program using only verified movements in my registry. Draft the complete program before making live changes.

> Search my verified Workout Registry for reusable sessions before creating new workouts for this program.

> Transfer the approved program into Trainerize one workout at a time, verify every save, and maintain the execution log.
